# zju-data-structures-pta
Solutions and C implementations for the PTA exercises accompanying Professor Chen Yue's Data Structures course at Zhejiang University. Includes Chinese explanations, algorithm analysis, and problem-solving notes for learning and reference.  浙江大学陈越老师《数据结构》课程配套 PTA 习题题解与 C 语言实现，包含中文解题思路、算法分析和学习笔记，供学习交流参考。
